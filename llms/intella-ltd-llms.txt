# Intella, LTD

> Intella is an enterprise Arabic AI company (founded 2021) building proprietary Arabic speech intelligence for banks, telecoms, and governments across the MENA region. Its intellaVX dialectal Arabic speech-to-text engine is exposed through a REST API for high-throughput CCaaS, CRM, and developer-tool integration. Backed by 500 Global.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Intella surface. No provider-published llms.txt, OpenAPI, or developer portal was found; the intellaVX REST API is documented as "clean, well-documented" but access is gated behind a demo/login request.

## Products
- [Ziila](https://intella.me/products/ziila): AI voice agent for inbound/outbound conversations across 25+ Arabic dialects
- [intellaCX](https://intella.me/products/intellaCX): Call-center conversation analytics for sentiment and friction detection
- [intellaMX](https://intella.me/products/intellaMX): Media translation and dialect-aware subtitling
- [intellaVX](https://intella.me/products/intellaVX): Dialectal Arabic speech-to-text engine with a REST API
